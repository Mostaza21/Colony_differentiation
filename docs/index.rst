Colony Differentiation
======================

Colony Differentiation is a Python-based tool for detecting, differentiating, and counting microbial colonies on agar plates based on their color and size. It supports both single-image and time-series analysis.

The software is particularly useful for analyzing colonies grown on differential agar media, such as CHROMagar, which can produce distinct colony colors that help distinguish different microbial populations.

For single images, the software provides tools to detect colonies and distinguish them based on their color and size, allowing users to count different colony populations.

For time-series data, the software allows users to examine how colonies develop over time and incorporate temporal information to support colony differentiation.

Additional image analysis and visualization tools are available to support the characterization of colonies.
