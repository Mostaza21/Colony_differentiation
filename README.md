# Colony Differentiation

A Python-based tool for detecting, differentiating, and counting microbial colonies on agar plates based on their color and size, supporting both single-image and time-series analysis.

- Read the [documentation](https://colony-differentiation.readthedocs.io/en/latest/) for detailed instructions and examples.
- Install the package with `pip install .` from the source directory.
- Install the additional requirements with `pip install -r requirements.txt`.
- Install the testing dependencies with `pip install ".[test]"`.
- Run the tests with `python -m pytest`.
- Launch the graphical user interface with `python -m streamlit run app.py`. The interface is currently under development.
- Use the GitHub issue tracker to report bugs or request features.
